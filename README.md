TechUp@GU

TechUp@GU is a workshop/seminar series that welcomes faculty and students who want to learn about data science. We expose people to marketable skills (R, Python, visualization, working with Terminal, using github, crowd-sourcing data collection, using supercomputers). People with different skills sign up to deliver a short self-contained topic. The audience comes with a laptop and follows along. You take home a piece of code you can run on your own and adapt. We benefit from the skills of people we have but also visiting researchers. Some folks have substantive puzzles and want to know what a tool can do for them (what good *is* text-analysis?), other people want to improve their familiarity with a programming language or specialized package. All the code created is available in a Github repository. We emphasize open science - free tools, non-proprietory approaches, transparency. Since BA and MA students can consider consider data science as a tool for their theses, teachers are encouraged to spread the word to that community.
